LIFEOS WEB APP — BETA GRATUITA

Contenido:
- index.html: aplicación completa en un solo archivo.
- manifest.webmanifest: configuración de instalación PWA.
- sw.js: caché básica para uso offline tras la primera carga.
- icon.svg: icono provisional.

Publicación gratuita orientativa con GitHub Pages:
1. Crea un repositorio público en GitHub llamado lifeos.
2. Sube los cuatro archivos de esta carpeta a la raíz del repositorio.
3. En Settings > Pages, selecciona Deploy from a branch, rama main y carpeta /(root).
4. Guarda y espera a que GitHub Pages publique el sitio.
5. Abre la URL HTTPS en Safari en iPhone y usa Compartir > Añadir a pantalla de inicio.

Limitaciones:
- No incluye backend, cuentas, sincronización, pagos ni suscripciones.
- Los datos se guardan en el navegador del dispositivo.
- LIFEOS AI es un conjunto de respuestas locales, no un modelo generativo.
- Es una beta funcional básica; hay que probarla en varios móviles antes de ofrecerla al público.
- No genera ingresos por sí sola. No se ha configurado ningún sistema de cobro.
- No publiques datos personales ni secretos en el repositorio.
